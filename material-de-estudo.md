-Conceito 1: Versionamento
O versionamento de software é uma forma de organizar e guardar todas as mudanças feitas
em um programa durante seu desenvolvimento. Assim, é possível acompanhar o que foi
alterado, quando aconteceu e como o projeto foi evoluindo.
-Conceito 2: Repositório
É o local onde ficam guardados os arquivos de um projeto e todo o histórico de alterações
feitas nele.
-Conceito 3: Commit
É como se fosse um salvamento do projeto, registrando as alterações feitas naquele
momento.
-Conceito 4: Branch
É uma cópia de uma parte do projeto que permite trabalhar em novas ideias ou mudanças
sem mexer diretamente na versão principal.
-Conceito 5: Merge
É quando juntamos as alterações feitas em diferentes branches, reunindo o trabalho em
uma única versão do projeto.
